# MVP_SCOPE.md

## Build First
- Idea intake for product, audience, tone, and publishing goal
- 7-day content calendar with scripts, captions, shot lists, and generation prompts
- Project history, section regeneration, and export packs for coding agents
- Simple intake form for Small shop owners, local retailers, Shopee/TikTok Shop sellers to provide their input (AI video app-specific fields).
- Core processing pipeline that transforms user input into 30-second product showcase videos with text overlays, background music, and transitions.
- Preview and download flow so users can verify output before sharing.
- Local-first storage so the app works without accounts or API keys.

## Acceptance Criteria
- Small shop owners, local retailers, Shopee/TikTok Shop sellers can complete the primary workflow without technical knowledge.
- The output (30-second product showcase videos with text overlays, background music, and transitions) is ready to use or share immediately.
- Demo mode works without API keys or external services.
- The app handles errors gracefully and shows clear status messages.

## Do Not Build Yet
- User accounts and cloud storage before the core workflow is validated.
- Payment processing before demand is proven.
- Advanced customization options before the default output is good enough.
- Full video rendering pipeline before validating prompt and script demand
- Unbounded media storage, background rendering queues, and paid video APIs in the first pass
- Heavy video rendering pipeline before validating scripts, captions, and planning outputs.
